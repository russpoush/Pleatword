# Word list sources

- `valid-guesses.txt`: every 5-letter word (8,672) from ENABLE (Enhanced North American Benchmark LExicon), compiled by Mendel Leo Cooper in 1997 and released to the public domain. Extracted from the copy bundled in the Perl module Games::Word::Wordlist::Enable (https://github.com/Abigail/Games--Word--Wordlist--Enable), whose README states the word list itself is in the public domain.
- `extra-guesses.txt`: newer everyday words ENABLE predates (emoji, inbox, login...). Hand-added; edit freely.
- `answers.txt`: 614 common words hand-picked for Squiggle. Every one is also in ENABLE.
